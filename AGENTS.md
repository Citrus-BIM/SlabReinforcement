# Работа с модулем армирования плит

Перед изменением поведения прочитать [актуальные требования пользователя](docs/requirements/slab-reinforcement-user-decisions.md). Они собраны из уточнений в ходе разработки; новые прямые указания пользователя имеют приоритет.

Актуальный состав bin: [одинаковые 10 имён файлов для доставки](docs/deployment/update-delivery.md) во всех R2019–R2027, без `data`, PDB и дочерних `.deps.json`. Не возвращать прежние разные наборы 9/5 файлов; содержимое DLL соответствует .NET своего года.

После нового уточнения обновлять соответствующий пункт этого файла требований. Не возвращать устаревшее поведение на основании старых протоколов испытаний или прежних макетов.

Последнее исправление порядка операций: [общее П после зон](docs/validation/2026-10-25-perimeter-after-zones.md). Нельзя считать любой существующий П доказательством уже созданного общего обрамления. Совпавшие физические стержни переиспользуются, недостающие группы достраиваются; один общий физический П должен иметь одну ссылку с объединёнными признаками предпросмотра. Погрешность считывания крайнего ряда обрабатывается в прежнем допуске без изменения координат или защитного слоя.

Последняя правка интерфейса: [минимум слов и свёрнутые подробности](docs/validation/2026-10-25-minimal-messages.md). Она заменяет предыдущую многословную редакцию. Ошибки и важные предупреждения остаются видимыми; обычный отчёт — в «Подробностях». Не скрывать блокирующие или неизвестные коды, не возвращать старые подробности после смены настроек/вкладки. Геометрия и правила выбора арматуры сохранены.

Последняя реализация: [максимальный диаметр и его шаг по связной линии](docs/validation/2026-10-25-connected-line-assignment.md). Она заменяет раздельное построение разных цветовых назначений одной линии и исторический выбор по максимальной As. Подключение: [загруженная сборка, центрирование и предпросмотр](docs/validation/2026-10-25-loaded-build-and-ui.md). Сохранены [примыкание границ зон](docs/validation/2026-10-25-zone-path-boundaries.md) и [создание по выбранной вкладке](docs/validation/2026-10-25-tab-scoped-creation.md), заменившее прежнее создание общего плана. Предыдущие реализации: [предпросмотр по вкладкам](docs/validation/2026-10-25-tab-scoped-preview.md), [зоны, локальные П и отмена](docs/validation/2026-10-25-zone-local-ends-and-cancel.md). Источники и предпосылки автоматической длины П: [расчёт нахлёста](docs/research/2026-10-25-automatic-u-lap-calculation.md).

Не сбрасывать чужие/предыдущие правки и не заменять установленный CITRUS без запроса. Итоговые сборки находятся в `SlabReinforcement/bin/R20xx` вместе с зависимостями; корневые DLL не являются автоматически обновляемым результатом сборки. При [отправке первого релиза в master](docs/validation/2026-10-25-master-release.md) опубликованы девять папок R2019–R2027; корневой набор отдельно синхронизирован с R2023 для прежнего загрузчика. Пользователь выбрал master и bin, без архивов и отдельного GitHub Release.

Фактическая кнопка Revit 2023 предпочитает `SlabReinforcement/bin/R2023/SlabReinforcement.dll` корневой DLL (подтверждено пользовательским journal.1084). Эта папка обновлена 25.10.2026. Если файлы удерживает Revit, сборка в отдельную папку сама по себе не обновляет кнопку; фиксировать, что ещё требуется подключение, и не считать копирование в корень достаточным. При UI-регрессии сверять путь и MVID загруженной сборки, а не только хеш текущего файла на диске.
