## Что заполняет модуль

Для штатных Rebar/Path фильтры используют ветку `Арм.ВыполненаСемейством = 0` и параметр **«Раздел»** (`NUMBER_PARTITION_PARAM`, id −1154614). Условия проверяют вхождение строк `низ X`, `низ Y`, `верх X`, `верх Y`, `фон` и `доп`; X/Y — латинские буквы.

| Компонент | Примеры значения «Раздел» |
|---|---|
| Фон | `низ X фон`, `верх Y фон` |
| Дополнительные зоны | `низ X доп`, `верх Y доп` |
| П с полками по X | `низ X верх X П-обрамление` |
| П с полками по Y | `низ Y верх Y П-обрамление` |
| П с наклонными полками в XY | `низ X верх X низ Y верх Y П-обрамление` |

Один П-стержень проходит обе грани плиты, поэтому получает признаки верха и низа своего направления. Направление определяется по фактической горизонтальной полке. `доп` в его раздел не добавляется: шаблон скрывает отдельные стержни дополнительных зон, оставляя представление Path. Общие шаблоны разрезов не содержат исключений по верх/низ X/Y. Существующие фильтры модуль не изменяет.

Разделители — пробелы. Фактическая проверка `NumberingSchema.IsValidPartitionName` показала, что Revit запрещает точку с запятой в имени раздела; исходный вариант с `;` заменён. Условия Contains сохраняют смысл.

| Дополнительный параметр | Правило |
|---|---|
| `Мрк.МаркаКонструкции`, GUID `5d369dfb-17a2-4ae2-a1a1-bdfc33ba7405` | Если на новом экземпляре есть доступный для записи String, копируется непустая фактическая марка основы `ALL_MODEL_MARK`. |
| `Метка основы`, `REBAR_ELEM_HOST_MARK`, id −1154619 | Штатная принадлежность основе; марка плиты не подменяется вымышленным значением. |
| `Орг.ЗонаРасположения`, GUID `215d6c56-3700-4db9-a5f5-53ec85b36daa` | Типовой параметр альтернативной ветки семейств; послойно не изменяется. |

Отсутствующие, read-only или неподходящие по типу хранения необязательные параметры пропускаются. Раздел native Path задаётся родительской системе и наследуется дочерними стержнями; доступная экземплярная марка конструкции заполняется и у дочерних RIS после регенерации.

Общие типы и формы сохраняются. В частности, не меняются флаг погонажа `Рзм.ПогМетрыВкл` (GUID `844a01e2-19fc-4dc5-baa0-a4bda30ef1f6`), типовой класс бетона и вычисляемый префикс формы. В этой версии шаблона форма `21 СК ГС` имеет read-only префикс `СК`; модуль не заменяет его на `П` и не назначает ручные позиции стержней.

## Условия конкретного проекта

Шаблоны планов перекрытия дополнительно проверяют, что штатная метка основы начинается с `ППм` и содержит примерный код комплекта `-33.33`; фундаментные шаблоны используют другие значения. Эти правила нужно согласовать с реальными марками проекта. Заполнение пользовательской марки конструкции не заменяет метку основы в штатной ветке фильтра.

Фильтры погонажа, изделий, молниезащиты и специализированных видов также остаются действующими. Например, выбор типа погонажа для П может скрыть его в плане соответствующим фильтром. Наличие правильного раздела само по себе не отменяет остальные настройки вида.
