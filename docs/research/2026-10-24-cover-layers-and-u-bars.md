# Защитные слои, отметки фона и П-обрамление

Решение согласовано с пользователем 24.10.2026: X — основное направление по выбранному ребру плиты; X располагается ближе к нижней и верхней поверхностям. Y — следующий внутренний слой. Общие П-стержни расставляются по нижним рядам, даже если шаг верхней сетки отличается.

## Источники и границы вывода

- [Autodesk: защитный слой арматуры](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-StructEng/files/GUID-4770D847-9CD5-4D12-AB0D-697D866CF88A.htm): защитный слой задаётся для основы или отдельных граней. В плагине используются параметры плиты «сверху / снизу / другие грани», расстояние до наружной поверхности арматуры.
- [Пособие НИИЖБ, 2017: плоские безбалочные перекрытия](https://files.stroyinf.ru/Data2/1/4293739/4293739389.pdf), приложение 2, страницы PDF 139–140: узлы с верхними и нижними рабочими стержнями, П-деталями и обрамлением отверстий. Иллюстрации проверены визуально. Это пособие к более ранней редакции СП; размеры отдельных примеров не перенесены в настройки как универсальные требования.
- [СП 63.13330.2018, рисунок 10.1, страница PDF 115](https://aksvil.by/upload/gost/sp-63-13330-2018.pdf#page=115): схема армирования плиты и свободного края. Схема не обосновывает прежнее чередование высоты П по чётности рёбер контура.
- [The Concrete Centre: Worked Examples to Eurocode 2, страница PDF 49](https://www.concretecentre.com/TCC/media/TCCMediaLibrary/Events/Online%20course/CCIP_Worked_Examples_EC2.pdf#page=49): обозначения наружных и внутренних слоёв в примерах деталей. Назначение конкретного направления наружным зависит от принятого узла. Для этого проекта оно явно задано пользователем.

Порядок X/Y ниже — согласованное правило проекта. Он не выдаётся за универсальное требование к любому перекрытию. Длина полки П остаётся вводимым размером принятого узла; этот блок не доказывает несущую способность нахлёста зон.

## Геометрия

За начало Z принята нижняя поверхность плиты, толщина — h, защитные слои — cн и cв. Диаметры физические, из Revit BarModelDiameter (BarDiameter в старых версиях).

| Слой | Высота оси от нижней поверхности |
| --- | --- |
| Низ X | cн + ØнX / 2 |
| Низ Y | cн + ØнX + ØнY / 2 |
| Верх X | h − cв − ØвX / 2 |
| Верх Y | h − cв − ØвX − ØвY / 2 |

Расстояние между осями соседних слоёв равно половине диаметра каждого из двух стержней. При отдельном создании слоя Y учитывается настроенный диаметр X, даже если флажок создания X сейчас снят. Снятый флажок не меняет отметку Y.

П X соединяет отметки нижнего и верхнего X; П Y — отметки нижнего и верхнего Y. Плановые координаты и направление полок берутся из фактических нижних рядов. Верхняя сетка не добавляет второй комплект П. Для существующего распознанного фона используются измеренные координаты.

Пример h = 200 мм, все диаметры 12 мм, cн = cв = 35 мм: оси снизу 41 / 53 / 147 / 159 мм. Высота П между осями полок: X = 118 мм, Y = 94 мм.

Боковой слой измеряется нормально к границе бетона, включая косые грани и отверстия. Поворачивается общая локальная система плиты, а не отдельный рисунок обрамления. Слишком большой диаметр П или полка, не помещающаяся в бетоне, дают конкретную ошибку без скрытого сдвига фона и укорочения полки.

## Поведение в Revit

Три исходных значения читаются из выбранной плиты. Предпросмотр не меняет документ. При создании изменяются только ссылки выбранной плиты на типы защитного слоя; общие типы других основ не редактируются. При ошибке создания вся операция, включая защитный слой и вновь созданные типы, отменяется.

Для простого стабильного MVP изменение защитного слоя из окна допускается до появления арматуры в этой плите. Если она уже есть, слой меняется в свойствах плиты, после чего команду следует открыть заново. Это исключает незаметное перемещение существующей арматуры при записи нового плана.

Проверки обычных пересечений стержней отключены по указанию пользователя. Проверки геометрии, защитного слоя и полных дублей сохранены. Предпросмотр показывает условную выборку рядов, полный план создания сохраняется.

Текущая производственная запись использует Rebar. Переход фона на штатное AreaReinforcement по одному объекту на слой — отдельная незавершённая часть согласованного процесса; результаты этого изменения её не подменяют.
