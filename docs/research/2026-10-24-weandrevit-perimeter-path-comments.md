# Weandrevit: обрамление и Path — уточнения по первичным материалам

Проверено 24.10.2026. Узкое чтение двух статей и всех доступных комментариев: 7 к Path и 15 к семействам, полученных из публичного WordPress API. Код и модель не менялись. Недоступное видео повторно не открывалось.

## Параметры обрамления

[Статья Александра Зуева о семействах обрамления](https://weandrevit.ru/para-novyh-armaturnyh-semejstv/) опубликована 24.03.2016, дата обновления страницы — 04.02.2023. Описаны независимые хвосты П, диаметр/шаг/класс, высота через толщину плиты и отдельные отступы сверху/снизу, поворот стержней для непрямоугольных сторон. Для семейства края отверстия предусмотрены 1–3 продольных ряда и один П на участке короче шага. Статья не задаёт нормативную длину хвостов и не объясняет достаточно точно, относятся ли все отступы к оси или поверхности стержня.

Ответы именно Зуева:

- 04.04.2016: старое семейство нельзя разложить по закруглённой грани ([вопрос и ответ](https://weandrevit.ru/para-novyh-armaturnyh-semejstv/#comment-149)); это не ограничение самого Path.
- 05.04.2016: для марки выбирать вложенный стержень через Tab; видимость — средняя/высокая детализация и прозрачная плита ([ответ](https://weandrevit.ru/para-novyh-armaturnyh-semejstv/#comment-145)).
- 06.04.2016: для шага семейства добавить в метку `Мсв.Шаг` с префиксом ([ответ](https://weandrevit.ru/para-novyh-armaturnyh-semejstv/#comment-140)). Это настройка тогдашней марки, не требование к штатному Path 2023.

## Особенности Path

[Статья Зуева о выпусках из плиты в стену](https://weandrevit.ru/vypuski-armatury-pri-pomoshhi-armatury/) опубликована 04.08.2016, обновлена 04.02.2023. Предложены типы отгибов 90° с фиксированными длинами; для каждого используемого типоразмера стержня автоматическую длину выключают и вводят свою. Для выпусков вразбежку — разные концевые отгибы и второстепенный чередующийся стержень с обратной настройкой. Это управление геометрией, а не расчёт анкеровки.

- 09.08.2016 Зуев подтвердил обход ограничения размеров отгиба в Revit 2015: измерение и дополнительная линия ([ответ](https://weandrevit.ru/vypuski-armatury-pri-pomoshhi-armatury/#comment-36)). Не переносим этот обход в требования к Revit 2023.
- 05.08.2016 комментатор **Unknown**, не автор, сообщил об опыте П-обрамления дверных проёмов через Path, неудобном повторном выборе основы и преимуществе «Метки основы» ([комментарий](https://weandrevit.ru/vypuski-armatury-pri-pomoshhi-armatury/#comment-39)). Это свидетельство пользователя старой версии, не новая рекомендация Зуева для края плиты.

## Что взять для блока 1

Наш вывод из материалов: отдельно задавать толщину/верхний и нижний отступы, хвосты, диаметр и шаг; проверять реальную геометрию, короткий участок и маркировку. Конкретную привязку защитного слоя, концевые положения и поведение углов штатного Path следует установить отдельным фактическим тестом Revit 2023. Старые обходы и запрет кривой грани у RFA не превращаются в проектные правила нового инструмента.

[Обновление шаблона 20.07.2022 / 14.01.2024](https://weandrevit.ru/obnovlenie-shablona-weandrevit-2020-2/) прямо подтверждает маркировку прямых стержней в Path. Две изученные статьи и их комментарии не устанавливают, какой инструмент автор сейчас предпочитает именно для П-обрамления. Отсутствие такого утверждения не опровергает применение Path.
