# Зоны по траектории и точный предпросмотр — 25.10.2026

## Принятое поведение

- За запуск создаётся выбранный слой зон: Низ X/Y или Верх X/Y. Каждая группа содержит минимум два стержня и записывается как штатный `PathReinforcement`.
- Одиночные ряды исключаются после унификации. Предпросмотр и запись используют одни `Bars`/`Groups`; диагностика явно сообщает количество пропущенных рядов. Если остались только одиночные зоны, операция без других новых компонентов не создаётся. Корректный новый фон/обрамление остаётся доступным.
- Допуск объединения редактируется и сохраняется, по умолчанию 600 мм. Сравнение ведётся с исходным первым рядом, без накопительного изменения эталона и повторного увеличения длины при округлении. Отверстия и совместимость П-окончаний проверяются для каждого итогового ряда.
- Отметка зоны соответствует фону. Без существующего фона применяется общий порядок X снаружи, Y внутри с учётом физических диаметров. Старое пользовательское смещение игнорируется; редактор удалён. Внутренний `AdditionalOffset` системы служит только для достижения вычисленной отметки.
- Читаются реальные позиции дочерних `RebarInSystem` из Path/Area. Созданные системы сверяются с принятым планом до принятия общей транзакции; несоответствие отменяет создание.
- Предпросмотр показывает все физические стержни, включая подтверждённый существующий фон. Убрано независимое разрежение фона и П-обрамления; подсказка навигации вынесена под чертёж.
- Исправлена потеря точной координаты граничного нижнего ряда: округление станции могло выбрать другой край вогнутого контура. Координата П-стержня теперь строится по точной станции фонового ряда.
