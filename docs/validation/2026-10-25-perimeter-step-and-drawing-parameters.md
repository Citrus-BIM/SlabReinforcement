# Шаг П-обрамления и параметры для чертежей — 25.10.2026

## Поведение

- Без нижнего фона П-обрамление создаётся самостоятельно по выбранным контурам с максимальным шагом из интерфейса. Начальное ручное значение — 200 мм.
- При одном нижнем направлении П-стержни сохраняют точные позиции его рядов. Стороны, не обслуживаемые этими рядами, дополняются с ручным шагом. Если ряд уже обслуживает косую сторону, второй комплект на ней не добавляется.
- При полном нижнем X/Y позиции и шаг определяются фоном, поле показывает значения X/Y и недоступно для редактирования. Учитываются новый и подтверждённый существующий фон. Верхний фон сам по себе не блокирует ручной ввод.
- Ручное значение сохраняется отдельно от автоматического отображения. Некорректный ручной шаг блокирует создание только там, где он действительно нужен. Изменение исходных данных сбрасывает подтверждение предыдущего расчёта.
- П-обрамление остаётся штатными наборами Rebar. Зоны по-прежнему создаются PathReinforcement из двух и более стержней.
- «Раздел» заполняется для нового фона, зон и П-обрамления. П-стержень содержит признаки верхнего и нижнего армирования своего направления и не содержит `доп`. При доступном параметре экземпляра `Мрк.МаркаКонструкции` копируется фактическая марка плиты. Параметры типов, марка основы и фильтры документа не изменяются.

Исследование официального шаблона, точные строки и привязки параметров: [Weandrevit](../weandrevit-drawing-parameters.md).
