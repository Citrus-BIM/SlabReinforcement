# Результат реализации 2026-10-24

Ветка: `codex/nts-slab-reinforcement`. Изменения находятся в рабочем каталоге; коммиты и развёртывание в установленный Revit не выполнялись.

Этот отчёт фиксирует первоначальную проверку на синтетических сценариях. Последующая проверка предоставленных DXF и внесённые по её результатам изменения описаны в [отдельном отчёте](2026-10-24-real-dxf-results.md).

## Реализовано

- Ядро netstandard2.0 с NetTopologySuite 2.6.0; отдельные проекты тестов и smoke-проверок.
- Локальные оси по выбранному прямому ребру плиты. Преобразования с сохранением высоты, поворота и отражения. Поворот подложки не меняет оси армирования.
- Геометрия CAD читается из экземпляра Revit в координатах модели, с уже применёнными единицами и масштабом. Raw DXF-парсинг с фиксированными метрами исключён из рабочего пути. Цвет — материал сетки, резервно цвет слоя с предупреждением.
- Фактические контуры и отверстия плиты, включая острова и дуги. Контроль постоянного сечения вдоль нормали: неподдерживаемые торцы/скосы/изменённая форма отклоняются.
- NTS-объединение и обрезка цветных областей; разрешение перекрытий по номинальному d²/s внутри одной марки стали. Несовместимые пересечения блокируются.
- Защитный слой учитывает фактический модельный диаметр. Полная анкеровка и округление сохраняются в одном доступном интервале плиты. Отверстия не заполняются допуском объединения.
- Группировка проверенных рядов, дедупликация, предел 1002 стержня в одном наборе, окончательная проверка каждого раскрытого стержня по контуру/защитному слою.
- Контроль пропущенных выступов зоны между рядами. Это проверка полноты дискретизации, а не расчёт несущей способности или грузовой площади.
- Один окончательный план для предпросмотра и создания. После транзакции Revit координаты и число стержней сверяются с планом; несовпадение откатывает всю группу транзакций.
- Интерфейс CITRUS: назначение типов и шагов, выбор слоя/оси, смещение по толщине, масштаб/перемещение/вписывание, диагностика, пересчёт с отменой и защитой от устаревших результатов.
- Настройки в LocalAppData, атомарная запись, перенос старого XML. Отсутствующий сохранённый тип арматуры требует явного выбора.

## Найдено и исправлено при проверке

- Увеличение группы рядов через диагональное отверстие.
- Исчезновение узкого отверстия при допуске объединения.
- Дублирование стержней после округления разных интервалов.
- Смешанная геометрия точек/линий/полигонов при касании подложкой края плиты.
- Превышение лимита Revit 1002 стержня в наборе.
- Использование номинального диаметра вместо модельного для защитного слоя.
- Использование верхнего контура наклонной плиты при отличающемся нижнем сечении.
- Потеря узкого выступа связной расчётной области между рядами.
- Скрытые нижние настройки при уменьшении окна.

## Оставшаяся проверка в Revit

Revit не был запущен, поэтому чтение реальной CAD-геометрии/цветов, выбор рёбер, работа ограничений арматуры, транзакционный откат и Undo требуют модельной приёмки по `docs/validation/revit-acceptance.md`. Сборка по API и smoke-проверки этого не заменяют.

Существующая таблица анкеровки перенесена без изменения чисел; её нормативная проверка не выполнялась. Расчёт коллизий с уже размещённой арматурой, автоматический выбор отгибов/нахлёстов и сечения по глубине для плит с вертикальными торцами при уклоне не входят в реализованный алгоритм.
