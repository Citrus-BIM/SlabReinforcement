# Создание только выбранной вкладки — 25.10.2026

[Актуальные требования пользователя](../requirements/slab-reinforcement-user-decisions.md). Это уточнение заменяет прежнее создание общего плана из обеих вкладок.

## Поведение

- **«Фон и обрамление»** создаёт только отмеченные фоновые слои и включённое общее П-обрамление.
- **«Зоны»** создаёт только зоны по траектории и необходимые локальные П-окончания. Даже если на вкладке фона включены все слои и общее П, они не создаются.
- Смена вкладки отменяет текущий расчёт, очищает готовый план и временно отключает создание. Только результат нового расчёта может быть принят; запоздалый результат другой вкладки отбрасывается.
- Проверяются общие параметры и входные данные выбранной операции. Неверные неиспользуемые значения другой вкладки не блокируют её создание. Диагностика и счётчики относятся к выбранной операции.
- Настройки обоих компонентов сохраняются из редакторов. Подтверждение зон не отключает сохранённые галочки фона/общего П и не меняет ручной шаг П.
- Вертикальное центрирование названий слоёв и разделённый предпросмотр предыдущей сборки сохранены.

## Зависимости зон от существующей арматуры

Подтверждённый существующий фон выбранного направления остаётся в `ReferenceBars`: его измеренные высоты, ряды и площадь используются для зоны, повторной записи фона нет. Заданный, но ещё не созданный фон не вычитается в режиме полной As и не задаёт сетку зон как существующий.

Для виртуального положения зоны Y нужен диаметр внешнего слоя X соответствующей грани; неиспользуемый шаг X не нужен и не подменяется значением 200. Уже измеренный Y распознаётся независимо от отсутствующего виртуального X. Неполный/неоднозначный действительно используемый существующий слой по-прежнему требует проверки.

Обнаружен и исправлен связанный дефект полной As: проверка покрытия принимала только числовые прямые XY, а подтверждённый фон хранил измеренную 3D `Centerline`. Для проверки покрытия теперь формируется временный XY-снимок только одного прямого горизонтального участка. Измеренная `Centerline` и координаты исходных `ReferenceBars` сохраняются.

## Защита фактической записи

Форма задаёт явный `CreationScope`; Session рассчитывает выбранные компоненты, а не вырезает их из смешанного плана. Режим `All` сохранён только для прежних программных вызовов; диалог его не использует.

Перед транзакцией `CreationScopeGuard` проверяет все новые стержни и группы. План другой вкладки отклоняется без записи. Существующие ссылки другого компонента допустимы как подтверждённые зависимости. Writer больше не строит словарь неиспользуемых цветовых назначений для типизированных групп; дублирующиеся скрытые настройки зон не мешают созданию фона.
