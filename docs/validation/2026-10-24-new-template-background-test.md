# Тест фона и П-обрамления на новом шаблоне

## Задача и исходные данные

Пользователь запросил отдельную тестовую модель по только что скачанному официальному шаблону Weandrevit. Это продолжение согласованного блока: четыре независимых штатных системы армирования по площади, общее П-обрамление, нахлёсты отдельно. Модель создаётся в Revit 2023 через `NewProjectDocument` из `Weandrevit_2020.rte`, опубликованного 07.05.2026. Старый RVT не используется как исходный документ.

SHA256 RTE: `3E72E731CCD62C316CD1F83332BF2608C022A1CB0859A93FCB126F189CF313E7`.

Плита повторяет верхний левый контур из «1 Слой.dxf»: 14 вершин, площадь около 1303,2101 м², без отверстий. Исходные координаты сохраняются, включая небольшой зубец. Толщина 200 мм, защитные слои 35 мм — параметры теста, не сведения из DXF.

## Явные настройки теста

Все диаметры — 12 мм; максимальный шаг — 200 мм. Для фона выбирается готовый тип погонажа с включённым параметром `Рзм.ПогМетрыВкл`, для П — обычный тип. Общие шаблонные типы не изменяются.

Направление X параллельно выбранному горизонтальному ребру. На обеих гранях X расположен наружнее Y. П находится снаружи фоновых слоёв. Это выбранная схема испытания, а не утверждение об обязательном порядке Weandrevit.

| Элемент | Отметка оси от верхней грани, мм |
|---|---:|
| Верхняя лапка П | −41 |
| Верх X | −53 |
| Верх Y | −65 |
| Низ Y | −135 |
| Низ X | −147 |
| Нижняя лапка П | −159 |

Разделение соседних фоновых слоёв 12 мм и сдвиг фона относительно П должны подтверждаться реальными осями RebarInSystem. Четыре отдельные Area не обеспечивают эту раскладку автоматически.

П-обрамление испытывается через открытые штатные PathReinforcement. Величина параметра длины Path проверяется отдельно от фактической прямой части лапки; не обозначается как расчётный нахлёст. Пересечения стержней допустимы по указанию пользователя. Совпадающие дубли и выходы за защитный слой проверяются отдельно.

## Условия проверки

- Происхождение нового документа, типы из нового RTE, сохранность исходного RTE.
- Четыре Area, ровно один активный слой в каждой, явные разделы/наименования.
- Фактические направления, отметки, количество физических стержней и максимальный шаг.
- П направлены внутрь бетона; прямые и дуги находятся в допустимом объёме. Проверяется каждый физический стержень, включая крайние на углах и малых рёбрах. Защитный слой измеряется до поверхности арматуры: торец прямого стержня может находиться в 35 мм от перпендикулярной грани; требование 41 мм для такой осевой конечной точки было бы ошибочным. Для боковой поверхности Ø12 расстояние до оси составляет 35 + 6 мм.
- Все исходные рёбра учтены; невозможные участки не пропускаются молча.
- Геометрия и количество сохраняются после SaveAs и повторного открытия.
- Отдельные виды слоёв, общий 3D, деталь края и разрез позволяют проверить модель вручную.

Этот тест не меняет production-команду или установленные бинарники. Проверка одного файла не доказывает работоспособность произвольных контуров, отверстий и других версий Revit. Фактический результат и ограничения будут добавлены после запуска.
