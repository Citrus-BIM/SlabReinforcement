# Защитные слои и П по нижней сетке

## Изменение

Внизу окна добавлены три поля защитного слоя: сверху, снизу и торец. Начальные значения читаются из выбранной плиты. Замена подложки сохраняет введённые значения, следующая плита получает собственные значения. Предпросмотр документ не изменяет.

Порядок слоёв соответствует согласованной схеме: нижний X у защитного слоя, Y выше на сумму половин диаметров; сверху зеркально. Выключение создания X не меняет отметку отдельно создаваемого Y. Такой же порядок применяется к отдельной зоне Y без фактического фонового слоя Y; измеренная отметка распознанного фона имеет приоритет.

П-стержни следуют концам фактических нижних рядов. Верхняя полка использует отметку соответствующего верхнего направления. Отдельный шаг П убран из интерфейса. Размер полки сохранён. Добавление П не сдвигает фон и не резервирует под него несколько диаметров. Новые группы П используют MaximumSpacing только там, где он воспроизводит исходные ряды; иначе группа разбивается, без добавления или удаления стержней.

Связь ручных зон с таким обрамлением адаптирована к фактическим станциям и косому ребру. Эта проверка геометрии не является расчётом нахлёста конкретного дополнительного стержня: поперечное смещение относительно отдельного П внутри диапазона станций пока не проверяется.

Описание формул и источники: [cover-layers-and-u-bars](../research/2026-10-24-cover-layers-and-u-bars.md).
