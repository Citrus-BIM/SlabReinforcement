# П-обрамление без полного фона и параметры чертежей

Пользователь подтвердил: при одном нижнем направлении дополнить остальные стороны ручным шагом; П-обрамление показывать на планах армирования и разрезах/узлах.

## Реализация

1. Восстановить редактируемый максимальный шаг П (сохранённое значение, по умолчанию 200 мм). Новый и подтверждённый существующий нижний фон задаёт реальные станции П. Полный нижний X/Y блокирует поле и показывает оба шага; верхний фон сам по себе поле не блокирует. Ручной шаг сохраняется отдельно при переключениях режима.
2. Без нижнего фона использовать самостоятельный расчёт по контуру. При одном направлении сначала сохранить П по фактическим нижним рядам, затем дополнить только рёбра, ещё не имеющие П. Проверять выбранные отверстия, защитные слои и отсутствие дублей. Самостоятельные П сохраняют существующую схему высот и проверки контакта; фон не смещается.
3. Заполнять существующий штатный «Раздел»: фон `низ X фон` и аналогичные направления; зоны `низ X доп`. Для П указать верх и низ своего направления, например `низ X верх X П-обрамление`; не обозначать П как `доп`, поскольку фильтр шаблона скрывает такие отдельные стержни в пользу Path. Использовать пробелы: фактический `NumberingSchema.IsValidPartitionName` запрещает точку с запятой в имени раздела.
4. При наличии доступного экземплярного `Мрк.МаркаКонструкции` копировать фактическую марку основы. Не присваивать вымышленную марку плите, не менять общие типы, формы, параметр погонажа и существующие фильтры видов.
5. Проверить Core, сессию, WPF и фактический Revit 2023: отсутствие/частичный/полный/существующий фон, геометрия всех П, запись параметров Path и дочерних стержней, прохождение настоящих фильтров официального шаблона.
