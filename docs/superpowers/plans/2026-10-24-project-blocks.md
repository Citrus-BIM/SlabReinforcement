# Работа над проектом по блокам

24.10.2026. Пользователь задал два блока: основное армирование с обрамлением; зоны усиления с обрамлением, анкеровкой и нахлёстом. Текущий фокус — блок 1. Каждый блок проходит последовательность: алгоритм → предпросмотр и настройки → проверка в Revit → фиксация результата.

**Уточнение пользователя 24.10.2026:** основной фон должен создаваться штатным `AreaReinforcement`, каждый слой отдельным объектом: низ X, низ Y, верх X, верх Y. Нахлёсты оформляются отдельной операцией. Это заменяет прежнее решение создания фона наборами `Rebar`. Текущая production-реализация ещё использует `Rebar`; переход и совместимость с зонами требуют отдельной проверки. Длина цельного фонового стержня сама по себе не становится требованием встроить нарезку в этот блок.

## 1. Основное армирование и обрамление

Работает без подложки. Включает низ X/Y и верх X/Y, направление по выбранному ребру, поворот плиты, защитные слои, максимальный шаг, отверстия и П-обрамление. Создание обрамления включается отдельно. Используется геометрия и типы текущего проекта Revit.

Начальная проверка исходников выполнена: основные механизмы уже реализованы в BackgroundPlanner, PerimeterPlanner, ReinforcementSession и RebarPlanWriter. Дальнейшие изменения выполняются по выявленным проблемам этого блока.

Критерии готовности:

- [ ] На прямоугольной, повёрнутой, ступенчатой плите и плите с отверстием крайние ряды и концы соблюдают защитный слой, шаг не превышает заданный.
- [ ] При включении/выключении отдельных направлений положение слоёв предсказуемо; фактический существующий фон не смещается молча.
- [ ] П-стержни, включая загибы и полные лапки, помещаются в толщине и контуре. Невмещающаяся раскладка даёт понятную причину отказа.
- [ ] В Revit каждый включённый фоновый слой представлен отдельным AreaReinforcement с одним активным направлением. Четыре включённых слоя дают четыре независимых объекта.
- [ ] Фон и П используют MaximumSpacing; положение по высоте, защитные слои и фактическая раскладка проверены после сохранения и повторного открытия. Предпросмотр фона должен соответствовать раскладке AreaReinforcement.
- [ ] Повторное создание полностью совпадающего армирования не даёт дублей; изменённое или частичное обрамление не дополняется вслепую.
- [ ] Удобство настроек и результата проверено на верхней левой плите из «1 Слой.dxf»; CAD не требуется для самой операции фона.

Первым проверяем положение стержней относительно защитного слоя и друг друга, затем шаг/крайние ряды, затем П-обрамление и повторные операции. Исторический протокол есть в docs/validation/2026-10-24-max-spacing-shared-u.md; он относится к прежней конкретной сборке и не отмечает эти пункты как новую приёмку.

## 2. Зоны усиления и оформление концов

Начинается после фиксации блока 1. Включает выбор подложки кнопкой на вкладке «Зоны», слой/плоскость CAD, подтверждение направления, цвета, типы, шаги и явные значения As при соответствующем режиме.

Окончания рассматриваются отдельно: прямая анкеровка, использование принятого П-узла, необходимый для выбранного соединения нахлёст. Схема узла и условия применения справочника определяются до реализации автоматического решения. Длина анкеровки, длина нахлёста и геометрический вылет лапки имеют отдельные значения и названия.

Критерии готовности:

- [ ] Зоны правильно читаются и располагаются при повороте плиты/подложки, учитывают отверстия и фактические отметки основного армирования.
- [ ] Замена источника обновляет карту и сбрасывает зависящие от неё подтверждения; отмена сохраняет прежний источник и настройки фона.
- [ ] Обрамление можно не создавать. Поддержанное существующее П-обрамление используется без повторных стержней при последовательной работе с низом и верхом.
- [ ] Для окончаний явно выбран способ оформления; неподходящий или непроверенный узел не объявляется автоматически обеспеченным.
- [ ] Справочники анкеровки и нахлёста разделены; для нахлёста зафиксированы источник, условия применимости и правило округления. Историческая таблица анкеровки не заменяется молча.
- [ ] Геометрия результата проверяется в Revit на карте «1 Слой» (низ X по принятому указанию), затем отдельно проверяются остальные направления на подходящих исходных картах.

Сейчас есть табличная прямая анкеровка и ручной геометрический режим окончания в П-обрамлении. Автоматическая проверка расчётной достаточности нахлёста не реализована. Исходные исследования: docs/research/2026-10-24-lap-tables.md.

## Общая граница блоков

Общий контракт — геометрия плиты, локальные оси, защитные слои, типы арматуры и фактически существующие стержни. Обрамление принадлежит плите, а не каждой отдельной карте верха/низа. Совпадение геометрии и отсутствие дублей проверяются отдельно от достаточности принятого узла.

Два блока остаются в текущем проекте и окне. Выделять отдельные DLL или перестраивать архитектуру ради разделения этапов не требуется. Для каждой приёмки сохраняются версия сборки, RVT и протокол; сборка для версии Revit сама по себе не считается проверкой в этой версии.
