# Slab reinforcement MVP implementation plan

> Agentic workers: use subagent-driven-development; keep tasks in this existing branch and preserve all user changes.

**Goal:** Create background, perimeter and additional reinforcement with a compact two-tab interface, then exercise the actual Revit 2023 API on a copy of the supplied model.

**Architecture:** Pure millimetre geometry stays in Core. The session snapshots Revit data, validates engineering inputs and combines plans. The writer creates the same explicit geometry in one atomic operation and verifies the committed result. UI tabs organize inputs; enabled components determine the combined operation, independently of the visible tab.

**Tech stack:** C#, NTS 2.6, xUnit, WPF, Revit 2019–2027 conditional APIs; real acceptance in installed Revit 2023.

## Contracts

- `PreviewParameters.IncludeZones`, `CalculationAxesConfirmed`, `DemandMeaning` (`Manual`, `AdditionalArea`, `TotalArea`), four `BackgroundLayers`, `Perimeter` options.
- Each enabled background layer names its direction, model type and spacing. X is the chosen edge, Y is perpendicular; layer order is explicit and determined from physical diameters.
- A numeric colour area is entered in mm²/m. TotalArea may credit only background generated in the same operation for the same direction/material. Missing values, incompatible axes/materials and deficits block creation.
- Composite plan groups carry explicit type, local elevation and distribution vector. Bent shapes carry explicit line/arc centreline geometry; the writer checks it after regeneration.
- Original DXF/RVT files remain untouched. Test manifests and copied models live under `artifacts/revit-smoke` with a unique application id.
