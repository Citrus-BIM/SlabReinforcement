# Единое назначение арматуры вдоль связной линии

Пользователь указал утрату прежней логики линий и подтвердил: выбирается наибольший номинальный диаметр вместе с шагом этого назначения. При равном диаметре выбирается меньший из назначенных шагов, затем стабильный идентификатор типа/назначения. Новый шаг не придумывается.

## Подтверждённое отличие

В `8209534` все выбранные цвета объединялись в направленные линии КЭ, после чего линия получала одну пару типа/шага. Исторически ранжировалась площадь `d²/s`; последнее уточнение пользователя явно заменяет это на диаметр. Анкеровка считалась после выбора типа по его диаметру/классу и бетону. Текущий `ReinforcementPlanner` строит ряды и анкеровку отдельно для каждого назначения: смешанная линия 12–20–12 остаётся раздельной. Две регрессии X/Y подтверждают отличие.

## Решение

Нормализовать выбранную геометрию **до** защитных отступов, построения рядов, анкеровки, локальных П и унификации. Использовать объединённые по назначениям области после пересечения с плитой. Между критическими поперечными координатами выделять связные продольные участки; каждому присваивать максимальный диаметр и его собственный шаг. Сохранять исходную геометрию: отверстия и невыбранные промежутки не заполнять прямоугольником. Допуск унификации 600 мм не использовать как допуск связности.

Обычные и добавочные ряды на общей поперечной границе должны иметь одного владельца; замкнутые геометрические полигоны сами по себе этого не обеспечивают. Группировка и штатные Path получают уже итоговый тип. Для одинаковых назначений использовать короткий путь без лишнего геометрического разбиения. Основной и публичный расчёт границ Path должны использовать одну нормализацию.

Изменение типа после построения стержней отклонено: оно оставляет старую анкеровку, отступы и П. Возврат старого обхода КЭ без проверки продольных разрывов также отклонён: тот мог перескакивать через пустоту внутри общей двумерной области.

## Численные режимы

Больший диаметр с собственным более редким шагом может иметь меньшую площадь на метр. В AdditionalArea/TotalArea передавать в Core исходный требуемый дефицит каждого цвета. Проверять итоговую пару против всех требований поглощённого участка и совместимости материала. Не уменьшать подтверждённый шаг автоматически. Для ручной раскладки численное требование отсутствует.

## Проверки

Смешанная линия 12–20–12; X/Y и верх/низ через Session; разные шаги; равные диаметры; разрывы и отверстия; только касающиеся области; смена назначения на границе рядов; общая анкеровка и П; неизменность входных данных; отмена и ограничение размера; недостаточная и достаточная численная площадь. Прогнать реальную карту с одинаковыми и смешанными назначениями и запись в Revit. Обновить каноническую сборку `SlabReinforcement/bin/R2023`, которую использует кнопка CITRUS.
