# Локальный пакет MVP для Revit 2023 — П-образное обрамление

Пакет содержит отдельную команду **«Армирование плит — MVP»**, рабочие DLL и лицензии. Поддержаны четыре слоя фона, только П-образное обрамление краёв/отверстий, зоны по цветной подложке, совместный предпросмотр и проверка геометрии. Фон и обрамление можно создавать без CAD. Проверяются новые стержни между собой и с поддержанной существующей арматурой выбранной плиты; фактическая геометрия повторно проверяется после записи в Revit.

## Установка вручную

1. Закройте Revit 2023. Откройте в Проводнике `%APPDATA%\Autodesk\Revit\Addins\2023`.
2. Скопируйте из корня пакета **оба элемента**: `SlabReinforcement.MVP.2023.addin` и папку `SlabReinforcement.MVP.2023`. Manifest должен лежать непосредственно в каталоге `2023`, DLL — внутри одноимённой папки. Сохраните имена: путь Assembly в manifest относительный.
3. Запустите Revit 2023, откройте отдельную рабочую копию модели. Команда находится в **«Надстройки → Внешние инструменты → Армирование плит — MVP»**.

Пакет ничего не устанавливает автоматически и не заменяет файлы CITRUS. Если в этом же процессе загружен старый модуль с именем сборки `SlabReinforcement`, отдельный GUID команды не изолирует одноимённые DLL: используйте отдельный тестовый профиль Revit без старого модуля. Файл `SlabReinforcement.dll.config` относится к пакету; менять `Revit.exe.config` не требуется.

## Первая раскладка

Выберите плиту и её прямое ребро — ось X. Выберите режим с подложкой или без неё. На вкладке **«Фон и обрамление»** задайте включённые слои фона; для П-элементов выберите внешний край и/или отверстия, тип, шаг и длину лапки. На вкладке **«Зоны»** задайте карту, направление, цвета, типы и шаги. Видимая вкладка не выключает компоненты другой вкладки.

Для исходного DXF единицы задаются явно; у предоставленных файлов «1–4 Слой» подтверждены **метры**. При резервном чтении слоёв/цветов из DXF программа сверяет размещённые вершины в обе стороны. Полная As, дополнительная As и ручное назначение — разные режимы. Численные значения вводятся в мм²/м; для полной As учитывается только совместимый фон, создаваемый в той же операции. Перед созданием проверьте общий предпросмотр и сообщения.

Это модель геометрии выбранной раскладки. Таблица анкеровки зон историческая; анкеровка концов фона и лапок П-элементов, стыки, разбивка на поставляемые длины и соответствие рабочей высоты `h0` расчёту не проектируются. Длина лапки задаётся пользователем как полная проекция от стойки до конца, включая загиб. Прямые зоны A240 блокируются. Отсутствие пересечений не подтверждает нормативные свободные расстояния. Подробности — в [инженерных границах MVP](../validation/2026-10-24-mvp-engineering-scope.md).

## Демонстрационная RVT

Если сборщик отдельно включил модель, она находится в `demo/MVP-demo.rvt` **от корня пакета**. Откройте её через **«Файл → Открыть → Проект»** в Revit 2023 как отдельный документ. Не переносите её поверх исходного проекта. Для просмотра уже созданной арматуры установка команды не нужна.

В текущий пакет включается демонстрация с П-образным обрамлением. Её схемы и параметры предназначены для проверки работы MVP, а не для выпуска проектного армирования. Копия не подтверждает достаточность сечений, анкеровок и узлов. Наличие demo в пакете само по себе не является протоколом испытаний; итоговые результаты относятся к конкретному прогону и сборке. Если `demo` отсутствует, пакет содержит только команду и документацию.

## Сборка пакета из исходников

После финальной сборки конфигурации R2023 выполните из корня репозитория:

```powershell
.\tools\Package-Revit2023.ps1
```

Результат: `artifacts/mvp-revit2023-u-only`; прежний пакет остаётся отдельно. Чтобы включить уже проверенную демонстрацию текущего варианта:

```powershell
.\tools\Package-Revit2023.ps1 -DemoModelPath .\artifacts\revit-smoke\MVP-demo.rvt
```

Скрипт не собирает проект и не запускает испытания. Он принимает только новый каталог внутри `artifacts` (`-Destination`), проверяет обязательные DLL/лицензии, копирует их и сверяет SHA256. Существующий каталог вызывает ошибку без перезаписи; при сбое частичный пакет сохраняется. `PACKAGE_READY.txt` подтверждает только завершение упаковки. Revit API, тестовый загрузчик, PDB и настройки пользователя не включаются.

Формат команды основан на [регистрации дополнений Autodesk](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API/files/Revit_API_Developers_Guide/Introduction/Add_In_Integration/Revit_API_Revit_API_Developers_Guide_Introduction_Add_In_Integration_Add_in_Registration_html.html); относительный Assembly приведён в [рекомендациях Autodesk, с. 12](https://damassets.autodesk.net/content/dam/autodesk/www/developer-network/app-store/revit/pdf/3%20Autodesk%20Exchange%20Publish%20Revit%20Apps%20-%20Preparing%20Apps%20for%20the%20Store_Guidelines.pdf#page=12). Точка входа сверена с исходником: `SlabReinforcement.SlabReinforcementCommand`; GUID команды — `3342DBE0-455B-42F4-9F8D-41C42E938DF5`.
