# Доставка обновлений SlabReinforcement

[SlabReinforcement.addinsdata.xml](SlabReinforcement.addinsdata.xml) — блок для общей схемы `addinsdata.xml`. Во всех `bin/R2019`…`R2027` одинаковые 10 имён файлов: 9 DLL и `SlabReinforcement.deps.json`. Содержимое соответствует Revit/.NET своего года. `netDxf.dll` больше не нужен.

`Year` подставляется в URL и целевой путь. Для каждого года источником служит его `SlabReinforcement/bin/R20xx`, а файлы на сервере размещаются в `Addins/20xx/RibbonCITRUSData/SlabReinforcement/`. Корневые DLL репозитория не являются источником для всех годов.

| Revit | .NET для файлов своего года | Количество файлов |
|---|---|---|
| 2019–2024 | .NET Framework 4.8; прежние зависимости NuGet | 10 |
| 2025–2026 | .NET 8; пять System.* из runtime pack 8.0.31 | 10 |
| 2027 | .NET 10; пять System.* из runtime pack 10.0.12 | 10 |

**Папку `data` в bin не копировать.** Она остаётся отдельной частью схемы и репозитория: TXT и две PNG. В bin также не входят PDB, тестовые файлы и Revit API.

Состав формируется самим `SlabReinforcement.csproj`: SDK создаёт `.deps.json` во всех конфигурациях; для современных .NET через `PackageDownload` загружается подходящий runtime pack и копируются только пять System.*. Это не меняет ссылки сборки, современный `.deps.json` или способ запуска внутри Revit.

## Проверка схемы

25.10.2026 обновлён только список файлов SlabReinforcement в предоставленном пользователем `addinsdata.xml`. Остальной текст файла и подпапка `data` сохранены без изменений; пути сохраняют `Year`.

После уточнения пользователя все девять конфигураций пересобраны с одинаковым составом. В каждой папке ровно 10 файлов, совпадающих со схемой, без подпапок; всего 90 файлов. Проверены целевые .NET в `.deps.json` и версии пяти System.*. Современные `.deps.json` остались побайтно прежними. Логи и результаты: `artifacts/uniform-bin-work/final-builds/matrix.json`, `artifacts/uniform-bin-work/validation.json`.

Теперь все перечисленные бинарные файлы присутствуют для каждого года. Для доставки этого модуля отбор отсутствующих файлов по версиям не требуется. Код клиента/сервера и файлы работающего сервера в этой задаче не изменялись.
