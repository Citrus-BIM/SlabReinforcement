# Доставка обновлений SlabReinforcement

[SlabReinforcement.addinsdata.xml](SlabReinforcement.addinsdata.xml) — блок для общей схемы `addinsdata.xml`. Он содержит объединение 10 уникальных имён файлов всех опубликованных сборок. Описание команды и две иконки в `data` сохранены; `netDxf.dll` заменён актуальными зависимостями.

`Year` подставляется в URL и целевой путь. Для каждого года источником служит его `SlabReinforcement/bin/R20xx`, а файлы на сервере размещаются в `Addins/20xx/RibbonCITRUSData/SlabReinforcement/`. Корневые DLL репозитория не являются источником для всех годов.

| Revit | Runtime-файлы своего года |
|---|---|
| 2019–2024 | 9 DLL: SlabReinforcement, Core, Dxf, NetTopologySuite и 5 System.* |
| 2025–2027 | 4 DLL: SlabReinforcement, Core, Dxf, NetTopologySuite; SlabReinforcement.deps.json |

Подпапка `data` с TXT и двумя PNG добавляется к каждому году отдельно. PDB, тестовые файлы и Revit API в схему не входят.

## Проверка схемы

25.10.2026 обновлён только список файлов SlabReinforcement в предоставленном пользователем `addinsdata.xml`. Остальной текст файла и подпапка `data` сохранены без изменений. Объединение имён сверено с 69 опубликованными runtime-файлами девяти версий; XML корректно разбирается, пути сохраняют `Year`.

## Особенность текущего обновлятора

В просмотренном локальном коде CitrusBIMWeb `AddinsInfoController` добавляет в ответ даже отсутствующие на сервере файлы (с `DateTime.MinValue`). В CitrusBIMClient `CheckAndCollectFilesForDownload` отсутствующий локальный файл включается в загрузку без проверки этого признака. Поэтому общий список сам по себе не исключает неприменимые файлы года: при отсутствии на сервере загрузка может завершиться ошибкой HTTP.

Перед доставкой разных наборов серверу нужно исключать файлы, отсутствующие в папке выбранного года, либо клиенту — пропускать такие записи. В этой правке изменена только схема SlabReinforcement; код клиента/сервера и серверные файлы не изменялись. Это наблюдение относится к локальным исходникам, а не к проверке работающего сервера.
